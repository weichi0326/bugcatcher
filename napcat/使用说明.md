# QQ / NapCat 安装与登录

QQ 与 NapCat 由 WebUI 按需安装和管理，不随仓库提交。用户只需双击项目根目录的 `启动配置页.bat`打开管理页；项目不提供独立的 QQ/NapCat 启动批处理入口。

## 首次安装

1. 在「QQ 管理」点击「下载并安装 QQ」。WebUI 下载并校验 NapCat 官方 Windows OneKey 安装组件，然后启动安装程序；如安装窗口要求确认，请按提示完成。
2. 页面识别到 QQ 和 NapCat 已安装后，在「概览」点击「启动全部」。
3. NapCat 在后台运行。二维码显示在「概览」和「QQ 管理」页面，用手机 QQ 扫码；登录后页面显示账号昵称、头像、QQ 号和安装版本。
4. 整合启动器在登录后把 OneBot 消息通道接到机器人归档端口，QQ 白名单群的有效文本才会进入归档。

OneKey 安装器来自 [NapCat 官方发布页](https://github.com/NapNeko/NapCatQQ/releases/latest)。安装后目录名通常包含版本号，例如 `NapCat.XXXX.Shell`；项目会动态查找，不依赖固定版本号。默认本机目录是 `napcat/NapCat.Shell.Windows.OneKey/`，也可在配置主表的 `napcat_integration.napcat_root`指定其他路径。安装器不会覆盖已识别的安装目录和账号资料。

## 账号与消息连接

- 更换账号：在「QQ 管理」点击「重新扫码登录」，网页会显示新的二维码。此操作会重新启动整合服务；登录成功后自动更新对应账号的连接配置。
- 已登录却没有新归档：先核对 QQ 群号是否在白名单，再到「运行管理」查看 QQ 消息连接、服务日志；必要时执行「重写连接配置」并重新启动全部。
- 「重写连接配置」修复的是 **NapCat 与本地 OneBot 归档接收端**之间的网络参数，不是飞书和 QQ 的直接连接。
- WebUI 默认监听本机 8088；机器人接收 OneBot 事件默认使用 5000，NapCat HTTP 默认使用 3000。统一在网页操作不改变内部进程和端口的分工。

本机安装目录、账号配置、聊天归档和运行日志均由 `.gitignore`排除。仓库只包含下载与管理安装器的源码。
